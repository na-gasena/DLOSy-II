# Drawing Lissajous Oscilloscopic Synthesizer II (DLOSy-II)

Web Audio API を用いた、オシロスコープ描画（Lissajous / リサジュー図形）と VCO ループ・モジュレーションを中心に据えた、ハードウェアライクな Web シンセサイザーです。

---

## 概要

DLOSy-II（DLOSy20）は、ブラウザ上で動作するシンセサイザー／サウンドデザイン環境です。**「VCO LOOP」** と **「DRAWING MODE」** を中核機能とし、パラメーターのカーブ・モジュレーションと、XY スコープ上に描いた軌跡そのものを波形として発音する機能を組み合わせています。

### 主な機能

- **VCO ループ・エンジン (`vco-loop.ts`)** ― 中核機能
  - 周波数 / カットオフ / レゾナンス / ボリューム / ADSR を、1 小節を周期とする**カーブでモジュレーション**。
  - **STEP / CONT**（ステップ更新 / 連続補間）2 モード。
  - 独立した **4 ボイス**構成（各ボイスに個別の ON/OFF・波形・カーブ・パターンバンク・位相 / レート）。
  - **パターンバンク（8 スロット）** とパターン・チェーン再生。
  - ボイス設定の **COPY / PASTE**（音作りを別ボイス／別パターンへ複製）。
- **波形描画 & XY スコープ (`drawing-mode.ts`)** ― 中核機能
  - マウス／タッチで描いた軌跡（波形）を XY Scope 経由でオシロスコープ波形として発音。
  - 複数スロット、スキャン速度プロファイル・エディター。
- **トランスポート・クロック (`transport-clock.ts`)**
  - PLAY / STOP のマスタークロック。VCO LOOP と DRAWING MODE を駆動（内部 / 外部 MIDI クロック同期）。
- **シンセ・エンジン (`audio-engine.ts`)**
  - 基本波形（Sine, Triangle, Square, Sawtooth）＋カスタム描画波形。フィルター（カットオフ / レゾナンス）と ADSR。
  - MIDI IN の SYNTH モードから発音。
- **アルペジエーター (`arpeggiator.ts`)**
  - 独自の ADSR エディターを備えたアルペジエーター（ARP タブ）。
- **VCO ループ・イージング (`vco-ease.ts`)**
  - モジュレーション進行に緩急（イージング）を与えるエディター（EASE タブ）。
- **グリフ検索 (`unim-search.ts`)**
  - 波形描画に流用できる字形（グリフ）の検索（GLYPH タブ）。
- **エフェクト・エンジン (`effects-engine.ts`)**
  - ディレイ / フィードバック / リバーブ等。ドラッグで並び替え可能なカードスタック。
- **MIDI 入力 & クロック同期 (`midi-in.ts`, `cv-clock.ts`)**
  - Web MIDI API による外部コントローラー入力（2 デバイス、CC ラーン、バンク）。
  - 外部 MIDI クロックへの同期（RATE 倍率、BPM 検出）。
- **オーディオ設定・プリセット (`audio-settings.ts`, `preset-manager.ts`)**
  - 出力デバイス / サンプルレート / レイテンシー設定。音色・パターンの JSON エクスポート / インポート。
- **パネル・レイアウト (`panel-layout.ts`)**
  - 各パネルのドラッグによるリサイズ・並び替え（配置は自動保存）。

> **メモ:** 旧バージョンにあった「ステップ・シーケンサー」「ドラムマシン」「MIDI OUT」および画面上の鍵盤 / SYNTH 音源パネルは削除されています。再生のマスタークロックは `transport-clock.ts` が引き継いでいます。

## 実行方法

Vite ベースの静的 Web アプリです。

### 前提条件

- [Node.js](https://nodejs.org/) (npm) がインストールされていること。

### セットアップと起動手順

1. **依存関係のインストール**
   ```bash
   npm install
   ```

2. **開発サーバーの起動**
   ```bash
   npm run dev
   # または
   npm start
   ```
   *※自動的にブラウザが開かない場合は、ブラウザで [http://localhost:3000](http://localhost:3000) にアクセスしてください。*

3. **本番ビルド / 型チェック**
   ```bash
   npm run build      # dist/ へ出力
   npm run typecheck  # tsc --noEmit
   ```

## 基本操作

1. **音声出力の有効化**
   ブラウザのセキュリティ制限のため、ページを開いた直後は音が出ません。**画面内の任意の場所をクリックまたはタップ**するとオーディオエンジンが初期化されます。

2. **再生 / 停止**
   ヘッダーの ▶ ボタン、または **スペースキー**で再生 / 停止します。VCO LOOP と DRAWING MODE がこのクロックに同期します。

3. **つまみ（Knob）の操作**
   画面上のつまみをクリックまたは上下方向にドラッグして値を調整します。

4. **画面・タブの切り替え**
   - センターパネルのタブ（`ARP`, `EASE`, `GLYPH`）をクリックして各機能にアクセスします。
   - `Tab` キーで、フォーカス中のパネルのアクティブなタブ / スロット / パラメーター表示を切り替えます。
   - `VCO LOOP` または `DRAWING` パネルがアクティブなとき、`1`〜`8` キーでパターン / スロットを瞬時に切り替えられます。

5. **外部 MIDI**
   左パネルの SETTINGS から MIDI IN（演奏 / CC）と MIDI クロック同期（SYNC）を設定できます。
